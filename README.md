# GG Alavancagem

Ferramenta para registrar entradas, acompanhar resultados e simular a progressão da banca.

## Funcionamento

- Site estático publicado pelo GitHub Pages.
- Registro manual de entradas com esporte, competição, partida, mercado, odd, valor e data.
- Histórico de entradas com opções Green, Red, Anulado e Cashout.
- Estatísticas de greens, reds, anuladas, cashouts, taxa de acerto, ROI e resultado líquido.
- Simulador de progressão hipotética da banca.
- Os registros ficam armazenados no navegador e não sincronizam entre dispositivos.

## Estrutura

- `index.html`: interface do GG Alavancagem.
- `css/style.css`: estilos e layout responsivo.
- `js/app.js`: navegação, registros, histórico, estatísticas e simulador.

## Privacidade

Os registros são armazenados localmente no navegador. O site não precisa de conta, chave de API, serviço externo de inteligência artificial ou servidor próprio para as funções atuais.
